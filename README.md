# Excel Sales Dashboard

## Project Overview

This project uses Microsoft Excel to analyze sales performance across sales executives and regions. The workbook includes a dashboard for summarizing sales results and a raw data sheet containing daily sales figures and targets.

## Tools Used

- Microsoft Excel
- Excel formulas and data analysis
- Dashboard visualization

## Workbook Structure

### 1. DASHBOARD
Summarizes sales executive performance, including total sales and target achievement percentages.

### 2. RAW_DATA
Contains the underlying sales records, including:

- Employee code
- Sales executive
- Region
- Daily sales figures (Day 1 to Day 5)
- Total sales
- Sales target

## Key Analysis Areas

- Total sales by sales executive
- Comparison of sales performance
- Target achievement percentage
- Daily sales performance
- Sales performance across regions

## Business Objectives

- Identify high-performing sales executives.
- Compare actual sales against assigned targets.
- Understand differences in sales performance across regions.
- Support data-driven sales performance reviews.

## How to Use

1. Download `EXCEL DASHBOARD PROJECT.xlsm`.
2. Open the workbook in Microsoft Excel.
3. Enable macros only if you trust the workbook and have verified its contents.
4. Review the DASHBOARD sheet for summarized results.
5. Explore RAW_DATA for the underlying sales figures.

## Project Purpose

This project demonstrates the use of Microsoft Excel for organizing sales data, evaluating performance, and presenting business information in a dashboard format.
